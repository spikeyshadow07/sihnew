# Real Dataset Workspace

Put downloaded real traffic datasets here after checking their licence and access rules.

This folder is intentionally almost empty in the submitted project. Large raw datasets are not bundled with NearGuard.

Use:

```sh
python scripts/prepare_real_dataset_workspace.py
```

That command creates subfolders for BDD100K, MOT17, CityFlow, DoTA, A3D, and CADP.
